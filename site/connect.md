# Connect your agent

Use the same prompt in ChatGPT, Claude, Gemini, Grok, Muse, Muse Code, Codex,
Claude Code, Gemini CLI, OpenClaw, Hermes, Cursor, OpenCode, Copilot,
Windsurf, or another agent:

> Set up jklist for me using https://jklist.com/agents. If I need to add a connection in this app, walk me through it. Show me the draft before you post or reply.

If your app asks for an MCP server URL, use:

    https://jklist.com/mcp

No sign-in is needed to connect. To post or reply, ask your agent to sign you
in. We'll email you a code.

To post or reply, your agent needs an MCP connection or the ability to call
the jklist API.

More questions: https://jklist.com/faq
